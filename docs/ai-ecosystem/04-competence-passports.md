# Паспорта профессиональных компетенций ИИ-аудиторов

Версия 0.1 · 2026-10-17 · статус: **проект на согласование**.
Архитектура проверки: [03-verification-architecture.md](03-verification-architecture.md).

**Как читать.** Коды в поле 3 (`L-…`, `S-…`) ведут в реестр
[`templates/13_knowledge_sources.csv`](templates/13_knowledge_sources.csv).
Сейчас **все источники имеют статус «не проверен»**: пока юрист или владелец
процесса их не верифицирует, ссылки агента на них сопровождаются пометкой
«Норма не верифицирована», а кейс уходит человеку. Коды процедур в поле 6
взяты из [`templates/10_control_thresholds.csv`](templates/10_control_thresholds.csv).
Процедуры с пометкой *(новая)* добавятся в шаблон после согласования.
Внутренние регламенты в поле 5 — **ожидаемые** документы (шаблон 09); если
какого-то документа в компании нет, это будет отражено в базе знаний.

**Общие границы полномочий для всех аудиторов** (поле 10 дополняет их):
- данные бизнес-систем — только чтение;
- запись — только в кейсы, журнал и задачи;
- нельзя изменять первичные документы, остатки, проводки, цены и лимиты;
- нельзя проводить платежи, блокировать отгрузки или серии;
- нельзя делать выводы о вине конкретного сотрудника;
- предлагать можно только действия, разрешённые `ACTION_POLICY`;
- нельзя изменять своё заключение после вмешательства проверяемого подразделения — только новая версия с причиной;
- критические нарушения нельзя закрывать без независимой проверки.

**Квалификация.** Для каждого аудитора эксперт компании (указан в поле
«Эксперт-разметчик») готовит эталонный набор из 30–50 кейсов. До его сдачи
аудитор работает в режиме «пилот».

## RET — Аудитор аптечной сети (Retail)

Включает действующих агентов: `cash-fraud`, `revision`. Эксперт-разметчик: директор розницы + СБ.

| # | Раздел | Содержание |
|---|---|---|
| 1 | Область | Розничная реализация ЛС и МИ в аптеках: касса, товарный учёт, ревизии, дефектура, возвраты, эффективность аптек |
| 2 | Знания | Порядок розничной реализации ЛС (в т.ч. рецептурных); кассовая дисциплина и ККМ; товарный учёт по сериям и срокам; инвентаризация и списания; программа лояльности; показатели эффективности аптеки (выручка на м², средний чек, конверсия, дефектура); схемы розничного мошенничества |
| 3 | Законы и НПА | L-01, L-02 (GPP), L-03, L-08 и L-10 (ККМ), L-11 (материальная ответственность — только для передачи человеку), L-15 |
| 4 | Стандарты | S-09 (GPP ВОЗ/FIP), S-06 (Fraud Tree), S-03 |
| 5 | Регламенты и СОП | Кассовая дисциплина; правила лояльности; порядок ревизий и списаний; стандарт обслуживания; работа с дефектурой; возвраты покупателей |
| 6 | Контрольные процедуры | RET-01…RET-08; RET-09 дефектура: отказы по SKU выше порога *(новая)*; RET-10 возвраты выше нормы по аптеке *(новая)* |
| 7 | Типовые нарушения | Пакетное аннулирование чеков в конце смены; возврат без исходного чека; ручные скидки «своим»; начисление бонусов на чужие карты; недостачи, совпадающие со сменами; невыполнение плановой ревизии; продажа рецептурного ЛС без рецепта (сигнал только из аудио/отзывов — всегда человеку) |
| 8 | Методы | Сравнение с порогом; профиль кассира против медианы аптеки и сети; временные паттерны; сверка ОФД ↔ 1С; связь недостач со сменами |
| 9 | Доказательства | Чеки и сторно (1С, ОФД), смены и логины касс, операции лояльности, акты инвентаризации, график работы |
| 10 | Границы | Не делает вывод об умысле кассира; персональные выводы — только кейс для СБ; не инициирует удержания |

| 6 | Контрольные процедуры | WHS-01…WHS-04; WHS-05 отгрузка ЛС покупателю без действующей фармлицензии *(новая)*; WHS-06 возвраты от клиента выше договорных условий *(новая)* |

| 9 | Доказательства | Реализации, оплаты, акты сверки, договоры и спецификации, история изменения лимитов, сведения из реестров юрлиц и лицензий |
| 10 | Границы | Не останавливает отгрузки — только рекомендует (L3, директор опта + директор по контролю); не оценивает кредитоспособность для коммерческого решения |
