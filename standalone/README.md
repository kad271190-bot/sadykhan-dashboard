# Автономная версия для сервера компании

Исходники сервера, который запускает AI-экосистему без Claude: `server.js` (Node.js 22+, без зависимостей) и `public/claude-local.js` (замена `window.claude.use` для хранилища, файлов и ИИ).

Готовый пакет собирается из `demo/sadykhan-ai-ecosystem.html`: в `public/index.html` подключаются `claude-local.js`, локальные копии lucide, jszip, pdf.js и шрифта Open Sans.

Начальные данные компании (папка `seed/`: документы и аудит закупа) в репозиторий не входят: это внутренние документы. Они передаются только в архиве пакета.

Установка — в `ИНСТРУКЦИЯ.md`.
