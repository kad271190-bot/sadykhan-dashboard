# Что это

Автономная версия платформы. Работает на сервере компании и открывается в браузере по отдельной ссылке: Claude и учётная запись Claude пользователям не нужны.

| Функция | Как работает в этой версии |
|---|---|
| Все разделы, аудиторы, кейсы, реестр СОП, сеть аптек, матрица | Работают полностью, без интернета |
| «Документы» (база знаний), загрузка файлов, версии, решения | Хранятся на сервере в папке `data/`. Все сотрудники видят одни и те же данные |
| Аудит закупа (реальные данные 2 кв. 2026) | Перенесён из Claude-версии, хранится на сервере |
| ИИ-агенты: ответы, трёхуровневая проверка, правовой аудит СОП, стратегический совет, распознавание сканов | Работают, когда на сервере указан ключ Anthropic API. Без ключа платформа работает, а ИИ-функции показывают «ИИ не настроен на сервере» |
| Интеграции 1С, Bitrix24, ОФД | Как и раньше — имитация на тестовых данных |

Уже перенесено в пакет (папка `seed/`):

- 43 загруженных СОП с текстом и оригиналами PDF;
- реестр юрлиц базы знаний;
- данные аудита закупа.

При первом запуске сервер копирует их в рабочую папку `data/`.

# Требования к серверу

- Linux (рекомендуется Ubuntu Server 24.04 LTS) или Windows Server 2019+.
- Node.js 22 LTS или новее. Другие программы и библиотеки не нужны: зависимостей нет.
- 2 vCPU, 4 ГБ ОЗУ, 40 ГБ SSD. Этого хватает на десятки пользователей и тысячи документов.
- Входящий доступ: только из сети компании или VPN, порт 443 (или 8080 без HTTPS).
- Исходящий доступ: `https://api.anthropic.com` (порт 443) — только для ИИ-агентов.

# Установка на Linux (рекомендуется)

1. Установить Node.js 22 LTS. Например, из официального репозитория NodeSource или пакетом дистрибутива.
2. Скопировать папку `sadykhan-ecosystem` в `/opt/sadykhan-ecosystem`.
3. Создать пользователя и передать ему папку:
   `sudo useradd -r -s /usr/sbin/nologin sadykhan && sudo chown -R sadykhan /opt/sadykhan-ecosystem`
4. Создать настройки: `cp config.example.json config.json` и заполнить их (см. ниже). Права на файл — только для владельца: `chmod 600 config.json`.
5. Включить автозапуск:
   `sudo cp sadykhan-ecosystem.service /etc/systemd/system/ && sudo systemctl enable --now sadykhan-ecosystem`
6. Проверить: `systemctl status sadykhan-ecosystem` и открыть `http://<адрес-сервера>:8080`.

# Установка на Windows

1. Установить Node.js 22 LTS с nodejs.org.
2. Скопировать папку, например в `C:\sadykhan-ecosystem`.
3. Скопировать `config.example.json` в `config.json` и заполнить.
4. Запустить `start.bat`.
5. Для работы как службы использовать NSSM или Планировщик заданий: «при запуске системы» → `node server.js` в этой папке.

# Настройки (`config.json`)

Каждую настройку можно задать и переменной окружения с тем же именем.

| Параметр | Значение |
|---|---|
| `PORT` | Порт, по умолчанию 8080 |
| `HOST` | `0.0.0.0` — все сетевые интерфейсы; `127.0.0.1` — только локально (если впереди nginx) |
| `ANTHROPIC_API_KEY` | Ключ API для ИИ-агентов. Вносит IT прямо на сервере, ключ не пересылается по почте и в мессенджерах |
| `AI_MODEL` | Модель ИИ, по умолчанию `claude-opus-5-5` (наиболее точная). Для экономии — `claude-sonnet-5-5` |
| `AI_MODEL_QUICK` | Модель для быстрых запросов |
| `AI_MAX_TOKENS` | Предельная длина ответа, по умолчанию 8192 |
| `BASIC_AUTH` | Вход по логину и паролю в формате `логин:пароль`. Пусто — без пароля (только для закрытой сети) |
| `DATA_DIR` | Папка данных, по умолчанию `data` |

## Ключ ИИ

1. Компания создаёт организацию на `console.anthropic.com`, подключает оплату и создаёт ключ API.
2. Ключ вносится в `config.json` на сервере. Он хранится только на сервере: браузеры пользователей его не получают.
3. Оплата — по факту использования. Расход виден в консоли Anthropic. Там же можно задать месячный лимит.

## Если выход в интернет через прокси

Задать переменные окружения службы:

- `HTTPS_PROXY=http://прокси:порт`
- `NODE_USE_ENV_PROXY=1`

Если прокси подменяет сертификаты, дополнительно задать `NODE_EXTRA_CA_CERTS=/путь/к/корпоративному-сертификату.crt`.

# HTTPS и адрес

Рекомендуется поставить перед сервером nginx с сертификатом компании и внутренним адресом, например `https://audit.sadykhan.local`:

```
server {
  listen 443 ssl;
  server_name audit.sadykhan.local;
  ssl_certificate     /etc/ssl/sadykhan/audit.crt;
  ssl_certificate_key /etc/ssl/sadykhan/audit.key;
  client_max_body_size 30m;
  location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_read_timeout 600s;
    proxy_set_header Host $host;
  }
}
```

В этом случае в `config.json` укажите `"HOST": "127.0.0.1"`.

# Резервное копирование и обновление

- Все данные — в папке `data/`: `db.json` и `blobs/`. Её достаточно копировать ежедневно, например архивом по расписанию.
- Обновление версии: заменить `public/` и `server.js`, перезапустить службу. Папки `data/` и `config.json` не трогать.
- Папка `seed/` нужна только при первом запуске. Если `data/` уже создана, повторно данные из `seed/` не копируются.

# Безопасность

- В базе — реальные внутренние документы компании и данные аудита закупа. Доступ к серверу — только из сети компании или VPN. Включите `BASIC_AUTH` или закройте доступ на уровне сети.
- Размещайте сервер в Казахстане: в своём ЦОД или у казахстанского облачного провайдера. Закон РК «О персональных данных и их защите» требует хранить базы персональных данных на территории РК.
- Платформа только читает данные бизнес-систем. Решения по кейсам, СОП и документам принимают люди.
- При вызове ИИ текст запроса, включая фрагменты документов, передаётся в Anthropic API. Если это недопустимо для каких-то документов, не загружайте их или не задавайте ключ ИИ.
