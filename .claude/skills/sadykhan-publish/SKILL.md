# Выпуск страницы экосистемы

Страница: `demo/sadykhan-ai-ecosystem.html`. Закрытая страница: https://claude.ai/artifact/6hSq7KghFBUy7eZZAdvVZs — всегда обновлять **её** (параметр `url`), не создавать новую.

## Шаги
1. **Проверка рисков.** Выполни навык `sadykhan-risk-check` (файл `.claude/skills/sadykhan-risk-check/SKILL.md`) для этого выпуска. Открытый блокирующий риск — стоп.
2. **Автотест.**
   ```bash
   node .claude/skills/sadykhan-publish/scripts/check-page.js demo/sadykhan-ai-ecosystem.html
   ```
   Если менялся раздел с реальными данными, дополнительно прогони с локальной копией данных (scratchpad, не репозиторий):
   ```bash
   node .claude/skills/sadykhan-publish/scripts/check-page.js demo/sadykhan-ai-ecosystem.html <scratchpad>/proc
   ```
   Копию взять через `ArtifactData list collection=proc out_dir=<scratchpad>`. Тест должен закончиться строкой «ПРОВЕРКА ПРОЙДЕНА».
3. **Визуальная проверка изменённого места.** Скриншот затронутого раздела на 1360 px и 390 px через Playwright (Chromium в `/opt/pw-browsers`, `playwright install` не запускать), посмотреть глазами: нет пустых блоков, наложений, обрезанного текста.
4. **Сверка с опубликованной версией.** `Artifact read url=…` и сравнить сохранённую копию с файлом:
   ```bash
   diff <(sed -n '2,$p' <сохранённая копия>) <(git show HEAD:demo/sadykhan-ai-ecosystem.html)
   ```
   Если опубликованная версия содержит правки, которых нет в git (кто-то менял страницу в Claude), сначала перенеси их в файл. Без этого не публиковать.
5. **Публикация.** `Artifact publish file_path=demo/sadykhan-ai-ecosystem.html url=<ссылка выше>`; `capabilities` не передавать (сохраняются `sample, assets, db, downloads, user`). Короткая метка `label` о сути выпуска.
6. **Сохранение.** Коммит в рабочую ветку сессии с понятным описанием и `git push -u origin <ветка>`. В `main` — только через запрос на слияние и после подтверждения пользователя.
7. **Отчёт пользователю**: что изменилось, ссылка на страницу, «Проверка рисков: пройдена», результат автотеста, что осталось имитацией.

## Критерий результата
- `check-page.js` — «ПРОВЕРКА ПРОЙДЕНА» (код 0);
- публикация прошла в существующую ссылку, номер версии вырос;
- коммит отправлен в рабочую ветку, в `main` ничего не слито без подтверждения;
- в отчёте явно различены реальные данные и имитация.
